# pairwise-lod

## 题面（可直接粘贴）

按屏幕空间误差选择 LOD，并保证时间稳定。约束：误差小于阈值才降级；距离越远等级不减；无 LOD 时返回原等级；必须带滞回：距离在阈值附近抖动 ±5% 时等级不得来回跳变（同一对象连续调用等级切换次数有上界）；选择器需维护每对象状态且并发调用安全；10 万次选择不超过 200 ms；非法阈值、负距离、未注册对象要给出可区分的错误；返回等级必须落在 [0, levels)。验收：python -m pytest tests -q -k lod。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 非有限距离
- 10 万次耗时
- 并发
- 阈值边界
- 负距离

```bash
python -m pytest tests -q
```
